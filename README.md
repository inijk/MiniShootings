# タダサバイバー(TadaSurvivor)

## 概要
- `pygame`で作った２作目の作品。前作よりは真面目に作っている(?)
- ステージクリア系のシューティングゲーム

## ゲームシステム
- 敵(青丸)に触れると*HP*が減少し、HPが0になるとGameOver
- マウスカーソルの方向に弾を発射する
- 弾を発射するたびに<u>*OH:オーバーヒート*</u>ゲージが溜まる。最大になるとゲージが0️になるまで弾が発射できない
- 敵に攻撃を当て続けると*BR:ブレイク*ゲージが溜まる。最大になると武器よって異なる特殊なスキルが発動する
- BRはダメージを受けると減少し、連続で攻撃を当てる(*Combo*)ほど溜まりやすい

## 操作方法
最初にチュートリアルステージを遊ぶことをおすすめします
- 決定：[Space]/[Enter]
- 戻る：[Esc]
- 移動：[wasd]
- 発射：左クリック

## 遊ぶには…
リポジトリの`tadasurvivor`フォルダをダウンロードし、フォルダ内の`TadaSurvivor.exe`を実行

# 普通のシューティングゲーム

## 概要
- `pygame`で作った最初の作品。かなりバカゲー
- ウェーブ進行系のシューティングゲーム

## ゲームシステム
- 敵の弾(*ぴえん*など)に触れると*HP*が減少し、HPが0になるとGameOver
- *ST:スタミナ*を消費して、*バースト*や*回復*が可能
- *バースト*中は弾の連射速度が速くなる

## 操作方法
最初にチュートリアルステージを遊ぶことをおすすめします
- 決定：[Space]
- 移動：[wasd]
- 発射：[Space]
- バースト:[Ctrl]
- 回復:[z]

## 遊ぶには…
リポジトリの`シューティング`フォルダをダウンロードし、フォルダ内の`NormalShoot.exe`を実行

※⚠フォルダ内の画像を削除すると起動しなくなる
