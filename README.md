# タダサバイバー(TadaSurvivor)

## 概要
- `pygame`で作った２作目の作品。前作よりは真面目に作っている(?)
- ステージクリア系のシューティングゲーム

## ゲームシステム
- 敵(青丸)に触れると*HP*が減少し、HPが0になるとGameOver
- マウスカーソルの方向に弾を発射する
- 弾を発射するたびに<u>*OH:オーバーヒート*</u>ゲージが溜まる。最大になるとゲージが0️になるまで弾が発射できない
- 敵に攻撃を当て続けると*BR:ブレイク*ゲージが溜まる。最大になると武器よって異なる特殊なスキルが発動する
- BRはダメージを受けると減少し、連続で攻撃を当てる(*Combo*)ほど溜まりやすい

## 操作方法
最初にチュートリアルステージを遊ぶことをおすすめします
- 決定：[Space]/[Enter]
- 戻る：[Esc]
- 移動：[wasd]
- 発射：左クリック

## 遊ぶには…
リポジトリの`tadasurvivor`フォルダをダウンロードし、フォルダ内の`main.exe`を実行
